# Dewdesk

Live video wallpapers, real-time weather effects, Lock Screen videos and a little dewdrop pet. A free menu bar app for
Macs with Apple silicon (macOS 14 Sonoma or later).

**Website and download:** https://pratyushiitbombay.github.io/dewdesk

Downloads are on the [Releases](https://github.com/pratyushiitbombay/dewdesk/releases) page. Dewdesk isn't signed with a
paid Apple developer account, so macOS asks you to approve it once: the website explains how.

This repository holds the website only. Videos shown are by ESO and NASA (credits on the page).
